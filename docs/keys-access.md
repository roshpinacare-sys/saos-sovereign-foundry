# חוזה גישת-מפתחות רב-סוכנית — Multi-Agent Keys Access Contract

Task 29-b · 2026-09-09 · סמכות: הנחיית-מפתחות של הבעלים (2026-09-08/09): "שאני יוכל לעבוד איתך ועם עוד סוכנים בצורה חכמה... שאוכל להישאר מחובר בצורה בטוחה".

## המבנה (מי מחזיק מה)

```
בעלים ──(מדביק מפתח רק במסך-השליטה)──▶ /api/saos/owner-keys ──▶ external-signer :3033
                                                                     │  verify-then-write
                                                                     ▼
                                              מעטפת חתומה SAOS-FLEET-VAULT-1 (AES-256-GCM, 600)
                                                                     │  in-memory only
                                                                     ▼
                                              כל סוכן/צ'אט ──▶ agent/lib/keys-access.cjs ──▶ /sign ──▶ שרשרת
```

- **מפתחות פרטיים** חיים במקום אחד בעולם: המעטפת המוצפנת + זיכרון-התהליך של החותם. לא בריפו, לא בלוגים, לא בצ'אט, לא בתיקיות-עבודה.
- **הבעלים** מחבר/מחליף מפתחות רק דרך מסך-השליטה → אבטחה ומאגר → "מפתח-בעלים" (או קובץ שנקלט ונגרס מיד). תמיד verify-then-write: רק מפתח שתואם רשות-חיה מתקבל.
- **סוכנים (אני, צ'אטים נוספים, תתי-סוכנים)** לעולם לא נוגעים במפתח. הם מבקשים חתימה.

## איך סוכן עובד (כל צ'אט, כל תיקייה)

```bash
node /tmp/agent-audit/steem/agent/lib/keys-access.cjs status   # מה מחובר ומה תואם (נתונים ציבוריים בלבד)
node /tmp/agent-audit/steem/agent/lib/keys-access.cjs health   # חיות + יכולות
node /tmp/agent-audit/steem/agent/lib/keys-access.cjs sign '{"requestId":"op-1","network":"HIVE","kind":"transfer_to_vesting","account":"headcorner","amount":9.682}'
```

תשובה היא `{ok, txid, account, network, kind, role}` — או סירוב כנה (`authority-gate`, `rc-gate`, bounds). אין דרך אחרת.

## הכללים הברזל (לכל סוכן, ללא יוצאין)

1. **לעולם** לא לקרוא/לכתוב/להדפיס/להעתיק קבצי-מפתח (`agent/.env`, `agent/keys/*`, תוכן `fleet_keys.enc`).
2. **לעולם** לא להדביק מפתח בצ'אט, בלוג, בקוד או ב-ticket. הבעלים מחבר מפתחות רק במסך-השליטה.
3. הכלי הוא **הדרך היחידה** לבקש חתימה. עקיפת שער = הפרה חמורה.
4. אפס ערכי-סוד בכל פלט: פסיקים, txid, שמות-חשבון ומפתחות-ציבוריים בלבד.
5. כשהמעטפת נעה/נמחקת (איפוס סנדבוקס): guardian מאתר גיבוי `guardian-*` החדש-ביותר ופותח; אין לשחזר ידנית עותקים מחוץ למנגנון.

## מצב נוכחי (ראו `status`)

- שער v2.2.0 כולל קליטת **סיסמת-אב** (P…): גזירת active+posting+memo לשני הרשתות, אימות מול רשויות-חיות, כתיבת ההתאמות בלבד. מפתח-owner לעולם לא נגזר/נשמר.
