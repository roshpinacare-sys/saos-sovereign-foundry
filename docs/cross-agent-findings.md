## 2. מה שווה / לא שווה / מסוכן

- **שווה (עתידית, באישור):** עיון עמוק ב-`steem` למודולי עיגון מוכחים-חי; השוואת `saos-sovereign-platform` לוודא קנוניות.
- **לא שווה כרגע:** `saos-repo` (מיושן/superseded), `saos-dex` (תחום אחר).
- **מסוכן:** `anchor-baseline` (.env בריפו), טוקן מוטמע ב-`saos-repo`, תוכן לא-ממופה ב-`steem`.

## 3. מה שולב בפועל (Task 12)

**כלום לא הועתק.** הרחבת ETHEREUM + SOLANA נעשתה **native** בפרויקט הזה:

- `src/lib/saos/networks/ethereum.ts` + `solana.ts` + `types.ts` — מודולי סטטוס יבשים, keyless, ללא-זריקות.
- חיבור מלא: `network-status.ts`, `anchor-gates.ts` (matrix), `signer.ts` (SignRequest + אימות-txid ציבורי), `anchor-preflight`, `status?probe=1`, UI (כרטיסי רשת + dropdown).
- **תוצאה:** אפס סיכון-רישיון, אפס סיכון-קוד-זר, אפס סודות; הכול מכוסה ב-35 הצהרות api-check החדשות (135/135).

## 4. מה דורש אישור בעלים

1. עיון עמוק בתוכן `steem` / `roshpina` / `saos-sovereign-platform`.
2. כל מגע ב-`Saosmartwallet` (מדיניות ארנקים).
3. פתיחת `anchor-baseline` רק לצורך הסרת/סיבוב ה-`.env` שבו.
4. מחיקת השיבוט המיושן `/home/z/saos-repo` + סיבוב הטוקן שמוטמע בו.

## 5. הפעולה הבאה בעלת הערך הגבוה ביותר

1. **ללא משאבים חדשים:** עיגון ראשון על STEEM לפי `docs/first-anchor-runbook.md` (שחזור כספת חיצוני + אישור בעלים) — הנתיב המוכח היחיד לעוגן אמיתי.
2. **אופציונלי (רשתות חדשות):** הגדרת `ETH_RPC_URL`/`SOL_RPC_URL` ציבוריים-ללא-מפתח → מיידית מתאפשר אימות-קריאה אופציונלי (`?probe=1`) — בלי כסף, בלי סיכון.
3. **היגיינה:** סיבוב הטוקן המוטמע ב-`saos-repo` + הסרת `.env` מ-`anchor-baseline`.
